# GyverLamp2 для Home Assistant

> Интеграция собрана с помощью нейросетки в свободный вечер без жестких требований по качеству, протестирована на собственной лампе и поставляется как есть.

Локальное управление лампой с прошивкой [GyverLamp2 от AlexGyver](https://github.com/AlexGyver/GyverLamp2) через Wi-Fi, без облака.
Реализация основана на официальных исходниках прошивки **0.23b**.

С прошивкой **GyverLamp (без двойки) несовместима**. Для первой версии используйте [AlexxIT/GyverLamp](https://github.com/AlexxIT/GyverLamp).

## Возможности

- Питание, яркость, выбор эффекта, скорость и масштаб.
- Цветовой круг и встроенные палитры для поддерживаемых эффектов.
- Отдельные настройки каждого эффекта с сохранением после перезапуска HA.
- Встроенная карточка: открывается по нажатию обычной плитки лампы.
- Управление через штатные действия HA и Node-RED.

Эффекты: Перлин, Цвет, Смена цвета, Градиент, Частицы, Огонь, Огонь 2020, Конфетти, Смерч и Часы.
Неподдерживаемые настройки скрываются. Редактирования Wi-Fi, прошивки и пользовательских палитр нет.

## Установка

### Ручная

1. Скачайте архив [репозитория](https://github.com/smeleshkin/GyverLamp2HA) через **Code → Download ZIP** и распакуйте.
2. Скопируйте каталог `custom_components/gyverlamp2` целиком в `/config/custom_components/` на HA.
3. Перезапустите Home Assistant.
4. Откройте **Настройки → Устройства и службы → Добавить интеграцию → GyverLamp2**.

### Из репозитория через HACS

1. Откройте **HACS → ⋮ → Пользовательские репозитории**.
2. Укажите `https://github.com/smeleshkin/GyverLamp2HA`, тип **Integration / Интеграция**, нажмите **Добавить**.
3. Найдите **GyverLamp2** в HACS и установите.
4. Перезапустите HA и добавьте **GyverLamp2** через **Настройки → Устройства и службы**.

Карточка входит в компонент и подключается автоматически.

## Подключение лампы

Укажите IP лампы, группу 1–10 и ключ связи из приложения (обычно `GL`). Закрепите IP в роутере.
Настройки подключения можно изменить кнопкой **Настроить** у интеграции.

**Slave** включайте только для лампы, которая уже работает в этой роли. Опция не меняет роль устройства, а разрешает установку общей яркости на максимум при включении.

**Требовать пакеты присутствия** проверяет доступность по broadcast-пакетам лампы. Если сеть их блокирует, проверку можно отключить.

## Что важно знать

- HA хранит собственный набор из десяти эффектов. Первая команда настройки заменяет набор режимов в лампе; настройки из Android-приложения не импортируются.
- Настройки оборудования, Wi-Fi и общая пользовательская палитра не изменяются.
- Прошивка сообщает присутствие и номер слота, но не питание и параметры. Значения в HA — сохранённые настройки, а успешное действие означает отправку команды без подтверждения от лампы.
- После запуска HA питание может отображаться как неизвестное до первой команды. Сам запуск ничего в лампу не отправляет.

## Node-RED

Используйте обычный узел Action Home Assistant и действие `gyverlamp2.set_mode`:

```yaml
action: gyverlamp2.set_mode
target:
  entity_id: light.gyverlamp2
data:
  mode: particles
  hue: 240
  speed: 80
  scale: 120
  brightness: 180
  turn_on: true
```

`turn_on` по умолчанию выключен: изменение параметров само по себе не включает свет.
Ключи эффектов и поля действия описаны в [документации управления](docs/control.md).
Есть [пример потока](examples/node-red.json).

## Обновление и разработка

Обновите компонент через HACS или замените каталог `custom_components/gyverlamp2` целиком, затем перезапустите HA и обновите интерфейс. Сохранённые настройки останутся.

Python 3.14, проверено на Home Assistant 2026.10.4. Фронт — TypeScript и Lit; готовый JS входит в компонент.
