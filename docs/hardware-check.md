# Проверка на лампе — 2026-10-31

Лампа пользователя: `192.0.2.107`, группа 1, ключ предположительно GL.
Тесты выполнялись с Mac в домашней сети, без прошивки и изменения сетевых настроек.

| Проверка | Результат |
| --- | --- |
| TCP-порт 80 | Соединение устанавливается; это не доказательство рабочего HTTP UI |
| UDP `GET` на 8888 (проверка старого протокола) | Ответа нет |
| `GL,0,1,<время>` и затем `GL,0,5,<время>` на 61197 | Пользователь подтвердил реакцию лампы |
| `GL,4,2,255`, затем `GL,4,2,64` | Отправлены; визуальное подтверждение не получено |
| Пассивный heartbeat на Mac, GL группы 1–10 | Не получен |
| Пассивный heartbeat из SSH-дополнения HA | Не получен, но дополнение находится в Docker bridge отдельной подсети; это не проверка сети HA Core |
| Точная версия/роль/список пресетов | Протокол не сообщает; требуют данных из приложения |

Успешная отправка UDP не приравнивается к подтверждению физического результата.
Возможность яркости/абсолютного пресета пока разрешается только явным параметром
Slave. Не меняли роль, Wi-Fi, группу, EEPROM-структуры, палитры или прошивку.
Питание и следующий пресет могут запустить штатную отложенную запись EEPROM,
как и управление из приложения. Последняя тестовая команда яркости — **64/255**;
если она поддерживается ролью лампы, это текущая установленная яркость.
