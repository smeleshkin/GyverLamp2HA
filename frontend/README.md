# Фронт GyverLamp2

TypeScript + Lit. Vite собирает один ES-модуль со стилями и зависимостями:
`custom_components/gyverlamp2/frontend/gyverlamp2.js`.
Интеграция подключает его автоматически; на HA Node.js и npm не нужны.

## Сборка

Node.js 22.12+:

```sh
cd frontend
npm ci
npm run check
npm test
npm run build
```

Редактируйте `src`, а не собранный JS. Готовый файл и `package-lock.json` должны
попадать в репозиторий: HACS не запускает сборку при установке.
Версии зависимостей зафиксированы, загрузок с CDN при работе карточки нет.

## Файлы

| Файл | Назначение |
| --- | --- |
| `lamp-card.ts` | Карточка и действия элементов управления |
| `lamp-dialog.ts` | Всплывающее окно HA |
| `color-picker.ts` | Цветовой круг, жесты и преобразование цветов |
| `lamp-state.ts` | Состояние и привязки сущностей |
| `command-controller.ts` | Очередь команд и ожидание обновлений |
| `popup.ts` | Открытие диалога по нажатию плитки |
| `constants.ts` | Диапазоны, таймауты и размеры |
| `styles.ts` | Оформление |
| `types.ts` | Типы данных HA и лампы |
| `index.ts` | Регистрация компонентов |

## Проверка в HA

Замените каталог компонента целиком, перезапустите HA и обновите страницу.
Адрес модуля содержит хеш сборки для обновления кэша.

Тесты используют Vitest и jsdom, без обращения к реальной лампе.
